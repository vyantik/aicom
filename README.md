# aicom

CLI утилита на Rust для генерации commit message с помощью Google Gemini на основе `git diff --staged` и последних коммитов.

## Возможности
- Генерация сообщения коммита в формате Conventional Commits.
- Опциональное добавление описания структуры сообщения.
- Сохранение API ключа локально в пользовательском конфиге.
- Поддержка прокси (auto-detect + переменные окружения).

## Требования
- Rust (edition 2024).
- Git.
- Gemini API Key.

## Установка
Сборка из исходников:

```bash
cargo build --release
```

Запуск бинаря:

```bash
./target/release/aicom --help
```

## Быстрый старт
1) Сохранить API ключ:

```bash
aicom login <YOUR_GEMINI_API_KEY>
```

2) Добавить изменения в staging:

```bash
git add .
```

3) Сгенерировать сообщение:

```bash
aicom generate
```

Чтобы попросить модель вернуть структуру сообщения с описанием:

```bash
aicom generate --description
```

## Как это работает
- Берет `git diff --staged` и последние 5 коммитов.
- Формирует промпт и отправляет его в Gemini (`gemini-2.5-flash`).
- Печатает сгенерированный commit message в stdout.

## Конфигурация
API ключ хранится в пользовательском конфиге, управляемом `confy` (путь зависит от ОС).

## Прокси
Автоматически пытается обнаружить системный прокси и локальные порты популярных прокси.
Также поддерживаются переменные окружения `HTTPS_PROXY`, `ALL_PROXY`, `HTTP_PROXY`.

## Примечания по безопасности
API ключ хранится в незашифрованном виде в конфиге пользователя. Используйте ключи с минимальными правами.
